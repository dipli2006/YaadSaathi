# YaadSaathi — Project Documentation

This folder contains the current shared source-of-truth documentation for the YaadSaathi project.

## Current MVP Decisions

- Adaptive difficulty: **rule-based only**
- ML-based difficulty modification: **not implemented now**
- RAG: **not implemented now**
- Languages: **English + Hindi only**
- Elderly user and caregiver: **separate devices, accounts, and sessions**
- Backend: **Python + FastAPI**
- Database: **PostgreSQL**
- Frontend: **Flutter**
